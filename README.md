# 截图识别二维码

一个使用 Rust 编写的 Windows 桌面小工具：框选屏幕区域，识别其中的二维码，并展示识别结果。

## 项目目标

这个项目同时有两个目标：做出一个实用的截图识别二维码工具，以及通过亲手设计和实现它来学习 Rust。学习 Rust 是项目的核心目标之一，不能为了尽快交付功能而跳过解释或把大量代码一次性交给学习者。

## 学习与协作原则

- 按小步迭代：每次只引入少量概念，并在继续前说明这一阶段的目标。
- 先解释再实现：说明设计选择、相关 Rust 语法和它们解决的问题；遇到新概念时提供小例子。
- 一起完成：优先给出可理解的步骤和练习，让学习者参与编写、推理和调试，而不是直接生成完整项目。
- 解释错误：出现编译或运行问题时，说明错误信息的含义、原因和排查方法。
- 随项目进展调整教学深度；除非学习者明确要求，否则不省略关键解释，不一次性铺开后续所有代码。

## 产品范围

当前功能包括截图识别二维码、输入字符串生成二维码 PNG 图片，以及最小化到 Windows 通知区域；热键和历史记录等扩展功能暂不在范围内。

## 代码结构

- `src/main.rs`：程序入口、字体初始化和窗口句柄读取。
- `src/model.rs`：界面状态和截图选区共享数据。
- `src/view.rs`：主窗口与全屏选区界面，并将用户操作返回给控制器。
- `src/controller.rs`：应用流程、状态更新和视图动作处理。
- `src/services/`：屏幕截图与二维码解码服务。
- `src/services/qr_generator.rs`：二维码编码、灰度图生成和 PNG 保存。
- `src/system_tray.rs`：Windows 通知区域图标、菜单和窗口恢复回调。

## 使用方法

1. 在“生成二维码”区域输入字符串，点击“生成二维码”查看图片预览。
2. 点击“另存为 PNG…”打开 Windows 文件保存窗口，选择保存位置和文件名。
3. 点击“框选并识别二维码”，主窗口会立即隐藏并截取主显示器画面，随后显示全屏选区窗口。
4. 按住鼠标左键拖动，框住二维码后松开；按 `Esc` 可以取消。
5. 识别到的每个二维码内容会单独显示，并有对应的“复制内容”按钮。
6. 点击“最小化到系统托盘”或窗口最小化/关闭按钮，可将程序隐藏到右下角通知区域；双击托盘图标或选择“显示主窗口”恢复，选择“退出”结束程序。

当前版本截图并框选主显示器；一个选区内可以识别多个二维码。截图只在本机内存中处理，不会上传。

## 开发状态

核心流程已实现：屏幕截图、拖动框选、二维码识别与生成、PNG 保存和结果展示。运行项目：

```powershell
cargo run
```

截图使用 `screenshots`，图像处理使用 `image`，二维码识别和生成分别使用 `rqrr` 与 `qrcode`。中文字体从 Windows 字体目录运行时加载，不会嵌入 exe；若系统未安装微软雅黑、黑体或宋体，需先安装中文字体。

发布 Windows 版本：

```powershell
cargo build --release --locked
```

可执行文件位于 `target\release\qr-screenshot.exe`。Release 版本不显示终端窗口，并启用了体积优化。分发时通常只需要这个 exe。

项目学习路线见 [教学计划](.codex/doc/learning/learning-qr-screenshot-roadmap.md)，Rust 与 Java 语法对照见 [教学笔记](learning-notes/rust-java-differences.md)。
